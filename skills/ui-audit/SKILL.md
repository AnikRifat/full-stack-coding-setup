# Audit the interface

Inspect the actual screens, component system, responsive states, and relevant visual requirements. Evaluate hierarchy, spacing, typography, color contrast, states, consistency, responsiveness, and accessible interaction presentation.

Separate visual or component findings from journey, task-flow, and information-architecture issues; route the latter to [ux-flow](../ux-flow/SKILL.md). Base findings on the supplied interface and project conventions rather than generic trend advice.

Report actionable findings with affected screen or component, impact, and a practical correction. Do not silently redesign product flows while auditing visual UI.
