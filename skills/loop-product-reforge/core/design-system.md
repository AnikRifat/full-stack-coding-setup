# Design-system rules

No component invents a value. Use primitives → semantic tokens → component tokens; components consume semantic tokens. Use a 4px spacing base, deliberate type scale, semantic status colors, role-based names, one elevation recipe, and dark mode token remapping rather than inversion.

Ship component state matrices: default, hover, focus-visible, active, disabled, loading, error, empty, read-only, selected, long text/RTL, responsive behavior, keyboard contract, and accessible name. Use enumerated variants rather than boolean prop combinations. Dense operator tables need a compact mode, stable identity column, and tabular right-aligned numbers.
