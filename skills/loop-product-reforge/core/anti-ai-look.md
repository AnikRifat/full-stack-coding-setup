# Anti-generic design pass

Reject template tells: arbitrary gradients, default typography without a reason, symmetric SaaS-card kits, identical rounded cards and shadows, bento layouts without information logic, generic feature grids, universal fade-up motion, emoji icons, fake people or proof, and vague marketing copy.

Derive aesthetic choices from the product’s real world. Choose typography deliberately, use real names, content, data, and Bangla where the product requires it. Let visual structure encode hierarchy; vary components by role; use one purposeful motion moment and user-triggered motion elsewhere.

Apply the Chanel rule: remove one element before shipping. Keep correctness conventional: 320px responsive behavior, visible focus, reduced motion, AA contrast, real states, and fast loading are mandatory.
