# Accessibility floor

Use WCAG 2.2 AA as a minimum: 4.5:1 normal text contrast, 3:1 large text and visible focus/UI boundaries, and never color alone for status. Support complete keyboard use, visible focus, skip links, Escape, no focus traps, correct modal/route/async focus management, 24px targets and 44px primary touch targets.

Use real labels, semantics, landmarks, one `h1`, meaningful headings, buttons for actions and links for navigation. Preserve form input on error; expose inline and summary errors with proper associations. Support reduced motion, 200% zoom, 320px reflow, paste in authentication, and consistent help placement.

For Bangla or Banglish interfaces: set the right document language, use a Bangla-capable font, 1.6–1.75 line height, no Bangla letter spacing, correct digit/৳ rendering, and space for 1.4× string length.

Audit by unplugging the mouse, running axe as a floor, narrating tab stops, testing 200%/320px, and screen-reading the critical flow.
