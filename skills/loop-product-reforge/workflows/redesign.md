# Redesign

Redesign only when at least two are true: the IA mismatches the user’s mental model; core entities or states are absent; more than 40% of screens must change; the system cannot absorb the roadmap structurally; or one screen serves incompatible roles. Otherwise state plainly which refinement fixes the problem.

For an approved redesign, preserve validated requirements, map old-to-new flow and role responsibilities, define the target IA and state model, sequence migration work, retain regression checks, and mark intentionally deferred work. The output is a reviewable redesign spec before implementation begins.
