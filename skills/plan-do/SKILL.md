# Goal-driven planning

Follow the [sub-agent execution and immediate-question policy](../loop-zero-to-production/references/delegation.md). For a direct request, coordinate useful bounded agents within this skill's scope. When assigned as a worker, execute your bounded task and route questions and evidence to the parent coordinator; do not recursively start another team.

Read the applicable [personal context](../loop-zero-to-production/references/profile.md), [shared handoff contract](../loop-zero-to-production/references/handoff.md), and [planning method](references/plan.md).

Receive the goal or MVP brief, repository context, chosen architecture, constraints, and unresolved decisions. Inspect relevant code and project instructions. Reuse existing scope and criteria; read the coordinator's [product method](../loop-zero-to-production/references/product-method.md) for a true missing product decision and [arch-design](../arch-design/SKILL.md) for material structural choices.

Produce ordered, verifiable increments with dependencies and relevant decision points. Do not fabricate estimates, approval, or runtime capabilities. Resolve routine choices; ask consequential questions while preparing independent work.

Feed the plan into [init-this-project](../init-this-project/SKILL.md), [arch-design](../arch-design/SKILL.md), or [code-implement](../code-implement/SKILL.md) according to project state. Under [loop-zero-to-production](../loop-zero-to-production/SKILL.md), planning is an intermediate outcome and the authorized loop continues. A planning-only request finishes at the reviewable plan.
